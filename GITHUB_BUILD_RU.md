# Инструкция с телефона
1. Открой https://github.com/new и создай репозиторий `NEON-AI-UPSCALER`.
2. Распакуй ZIP и загрузи все файлы в репозиторий через Add file → Upload files. Убедись, что `.github/workflows/android-apk.yml` тоже попал в репозиторий. При необходимости включи «Версия для ПК» в браузере.
3. Нажми Commit changes.
4. Открой вкладку Actions → Build NEON AI UPSCALER APK. Дождись зелёной галочки.
5. Открой завершённый запуск и скачай Artifact `NEON-AI-UPSCALER-debug-apk`. Распакуй его и установи `app-debug.apk`.
6. Если сборка упала, пришли последние 30–50 строк лога.
